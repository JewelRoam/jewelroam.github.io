# CLAUDE.md

## Scope

Treat framework-specific conventions as optional. Prefer these repository rules when they conflict.

## Documentation

Write agent documentation only in `docs/<agent_name>/`. Keep documentation concise, self-explanatory, and stateless. Do not duplicate repository state or implementation details that code already expresses.

## Code

Keep comments rare and necessary. Prefer clear names, small modules, explicit inputs, and deterministic behavior over explanatory comments or hidden state.
